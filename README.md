# 挂播推流工具

一个基于 Python、Tkinter 和 FFmpeg 的 Windows 多平台直播推流管理工具。

适合管理多个直播平台、多个推流账号以及相互独立的视频推流任务。

## 当前版本

`1.0.0`

交流群：`1101062939`

## 功能特性

- 支持虎牙直播、斗鱼直播、哔哩哔哩直播预设平台
- 支持自定义添加其他 RTMP 平台
- 平台与账号分级管理
- 每个账号拥有独立的推流地址和视频文件
- 支持新建、编辑、删除推流账号
- 支持单账号启动、停止和批量启动、停止
- 支持账号复选框、全选、取消全选和反选
- 支持自动重连和重连次数统计
- 支持账号启动间隔和最大并发账号设置
- 支持实时查看 FFmpeg 推流日志
- 支持日志复制、清空和导出
- 支持视频文件选择和拖拽导入
- 支持视频首帧缩略图预览
- 支持视频时长、分辨率和编码信息读取
- 支持总览页面查看平台、账号和运行状态
- 支持账号搜索和状态颜色区分
- 支持最小化到系统托盘
- 支持单实例保护，避免重复启动
- 支持开机启动选项
- 支持关于页面和免责声明

## 界面说明

### 总览

总览页面用于查看所有平台和账号的运行情况，包括：

- 平台总数
- 正在直播数量
- 已掉线数量
- 平台运行状态
- 账号运行状态
- 重启次数
- 视频文件名称

### 平台管理

点击左侧平台后，可以进入对应的平台账号管理页面。

预设平台不可删除，自定义平台可以删除。平台本身不保存默认视频和默认推流地址，具体配置放在每个账号中。

### 账号管理

每个账号都是一个独立推流任务，需要分别配置：

- 账号名称
- RTMP 推流地址
- 视频文件
- 是否加入批量任务

账号之间互不影响，一个账号掉线不会直接停止其他账号。

## 使用方法

### 使用 EXE 版本

1. 下载 Release 中的 `挂播工具-1.0.0.zip`
2. 解压整个文件夹，不要只单独复制 EXE
3. 双击 `挂播工具.exe`
4. 进入平台页面，点击右上角“新建账号”
5. 填写账号名称和 RTMP 推流地址
6. 选择或拖入视频文件
7. 点击“启动”开始推流

### 配置推流地址

RTMP 地址通常由直播平台提供，可能由服务器地址、房间路径和推流密钥组成。

请完整复制平台提供的地址，不要自行修改参数。推流地址应以以下格式开头：

```text
rtmp://
```

或：

```text
rtmps://
```

## 运行设置

在顶部点击“设置”，可以调整：

- 自动重连间隔
- 账号启动间隔
- 最大并发账号数
- 自动重连开关

最大并发账号设置为 `0` 时表示不限制并发数量。

## 文件结构

```text
挂播工具/
├── 挂播工具.py
├── 启动挂播工具.bat
├── ffmpeg.exe
├── app-logo.ico
├── huya-logo.png
├── douyu-logo.png
├── bilibili-logo.ico
├── 1.mp4
├── 挂播工具.config.json
└── dist/
```

说明：

- `挂播工具.py`：程序源代码
- `ffmpeg.exe`：推流引擎
- `app-logo.ico`：程序图标
- 平台 Logo：左侧平台列表使用
- `挂播工具.config.json`：本地配置文件，首次运行后自动生成
- `dist/`：PyInstaller 构建输出目录

## 从源码运行

需要 Windows、Python 3.12 或兼容版本，以及 FFmpeg。

安装依赖：

```powershell
py -3 -m pip install pillow pystray tkinterdnd2
```

启动程序：

```powershell
py -3 "挂播工具.py"
```

## 打包 EXE

```powershell
pyinstaller.exe --noconfirm --clean --windowed `
  --icon ".\app-logo.ico" `
  --name "挂播工具" `
  --distpath ".\dist" `
  --workpath ".\build_all" `
  --specpath ".\build_all" `
  --add-binary ".\ffmpeg.exe;." `
  --add-data ".\huya-logo.png;." `
  --add-data ".\douyu-logo.png;." `
  --add-data ".\bilibili-logo.ico;." `
  --add-data ".\app-logo.ico;." `
  "挂播工具.py"
```

构建完成后，程序位于：

```text
dist/挂播工具/挂播工具.exe
```

## 配置文件注意事项

配置文件可能包含 RTMP 推流地址和推流密钥，目前以本地 JSON 格式保存。

请不要把以下文件提交到公开 GitHub 仓库：

```text
挂播工具.config.json
*.log
```

建议在 `.gitignore` 中排除配置文件、日志、构建目录和 `dist` 目录。

## 常见问题

### 点击启动没有推流

请检查：

- 视频文件路径是否存在
- RTMP 地址是否完整
- 地址是否以 `rtmp://` 或 `rtmps://` 开头
- `ffmpeg.exe` 是否位于程序目录或 EXE 的 `_internal` 目录
- 平台推流密钥是否已过期

### 日志显示配置错误

进入账号页面点击“编辑”，重新选择视频文件并检查推流地址。启动失败原因会写入账号日志。
